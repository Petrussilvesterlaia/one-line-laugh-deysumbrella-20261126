A tiny Python program that writes one deadpan joke to `entry.txt`: a balcony pigeon has been staring at its human like a landlord for three years, and the twist is that after all those free breadcrumbs, the bird might actually have a point. One line, no setup paragraph, no explanation — the laugh has to land in a single breath.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. Point it elsewhere with `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
